# ⌚ LuxeTime – Ladies Watches E-Commerce Website

### Elegance on Your Wrist, Beauty in Every Moment.

LuxeTime is a stylish and responsive e-commerce product gallery designed to showcase an exclusive collection of ladies' wristwatches. It features an elegant design, an attractive color scheme, and interactive product cards for a pleasant browsing experience.

## ✨ Features

- **Elegant User Interface:** Modern design with a burgundy, pink, and white color palette.
- **Responsive Product Gallery:** CSS Grid automatically adjusts product cards according to screen size.
- **Sidebar Navigation:** Simple navigation to different sections of the website.
- **Product Cards:** Display product images, names, descriptions, prices, and Shop Now buttons.
- **Hover Effects:** Smooth animations on product cards and buttons.
- **Clean Layout:** Organized header, sidebar, main content, and footer.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Transitions
- CSS Transformations

## 🎨 Design Highlights

- CSS Grid for the dashboard layout.
- `repeat(auto-fit, minmax(250px, 1fr))` for a responsive product gallery.
- Minimum product card width of 250px.
- Smooth hover animations.
- Consistent spacing, typography, and colors.

## 🎯 Project Objective

The objective of this project is to practice HTML and CSS concepts by developing a responsive e-commerce product gallery using CSS Grid without relying on external CSS frameworks.
